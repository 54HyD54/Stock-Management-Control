# Stock Management Control

A C# console demo for tracking quantities of four materials: stone, wood, iron, and gold.

## Features

- View the current quantity of each material.
- Add a selected material to stock.
- Use a selected quantity when enough stock is available.
- Navigate the inventory through a simple text menu.

## Technology

- C#
- .NET Framework 4.7.2
- Console application

## Run

Open `Stok Yönetim Kontrol.sln` in Visual Studio 2022, restore or retarget the .NET Framework 4.7.2 Developer Pack if prompted, then build and run the console project.

## Scope

Inventory quantities are held in memory and reset when the program closes. This project is a learning demo and does not use persistent storage.
